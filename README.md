# Perspective Visuals & Media Landing Page

A high-fidelity landing page for a South African photography and cinematography studio.

## Features
- Premium cinematic design with dark theme and red accents
- Dynamic scroll reveal animations
- Robust custom loader with safety fallback
- Filterable image gallery with lightbox
- Fully responsive layout for all devices
- Built with Vite for ultra-fast performance

## Development
To run the project locally:
```bash
npm install
npm run dev
```

## Deployment
This project is optimized for deployment on Vercel. Simply connect your GitHub repository and Vercel will handle the rest using the pre-configured `vite build` command.
